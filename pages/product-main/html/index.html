Sugita II Head Frame

Model SGT-II • SGT-II-RL (radiolucent)

  • Craniotomy
  • Skull Base
  • Aneurysm
  • Neuroendoscopy

The Sugita II provides secure 3-point cranial fixation with a lightweight aluminium frame. Available in standard and radiolucent configurations, compatible with all major neurosurgical approaches and navigation systems.

KEY SPECIFICATIONS
Configuration Standard + radiolucent versions
Pin configuration 3-pin or 4-pin
Maximum torque 4 Nm per pin (torque-limiting)
Navigation Compatible — all major systems
